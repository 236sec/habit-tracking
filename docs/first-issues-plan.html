Technical plan

System boundary

Request path

Browser → Next.js 16 → Axum 0.8 → PostgreSQL 16. Supabase Auth owns OAuth and sessions. The Next.js app renders Today and handles the OAuth callback. Axum owns account preferences, Habits, Planned-day decisions, and check-ins; SQLx owns migrations and queries.

Use provider-specific @supabase/ssr server clients with a PKCE callback. A Next.js proxy.ts refreshes cookies. Protected server views verify the session, and Axum validates the bearer token's signature, issuer, audience, and expiry before deriving the Account identity. Never authorize from an unverified cookie or a client-supplied Account ID.

Exact file seams: frontend/src/lib/supabase/, frontend/src/proxy.ts, frontend/src/app/auth/callback/route.ts, backend/src/handlers/, backend/src/usecases/, backend/src/repositories/, and backend/migrations/.

Gate before #2

Identity separation experiment

In disposable Google-only and GitHub-only Supabase projects, sign in with the same verified email. Inspect the resulting issuers, subjects, and Account UUIDs without recording tokens. Confirm distinct Accounts and stable return sessions. Cross-project explicit linking belongs to #16 and requires proof of control of both sessions.

Acceptance: same-email sign-ins expose separate app data until an explicit link. If the configured projects or verified JWT claims do not support the issuer-and-subject mapping, revisit ADR 0003 and #16 before closing #2.

This is a real spec/provider conflict, not a completed design choice. Supabase's current identity-linking documentation describes the automatic same-email behavior.

Time, security, and test setup

Local day contract

The browser supplies its current IANA time zone, such as Asia/Bangkok. Axum validates that identifier and derives today's local date from its clock for Today and today's check-in. Store calendar days as SQL DATE, not midnight UTC timestamps. A later trip changes the current time zone without rewriting past Planned days. The server owns the final Planned-day check.
